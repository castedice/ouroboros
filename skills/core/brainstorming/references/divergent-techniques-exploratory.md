# Divergent Techniques — Exploratory Set

This reference covers the divergence techniques used when fixation is high, the solution space is combinatorial, or ideas need iterative development.

## 8. Lateral Thinking

**Definition**: Intentionally break logical chains to discover directions that direct analysis would never generate.

**When to use**: Use it after logical techniques have started to return only obvious variations.

**Procedure**:

1. Create a provocation with `Po:`.
2. Extract a usable principle from the provocation instead of debating whether it is true.
3. Try a random entry or a full reversal.
4. Capture every novel direction before judging feasibility.

**Example**: `Po: The brainstormer should never produce ideas` can lead to anti-ideas that reveal hidden quality assumptions more clearly than positive ideas.

**Pitfalls**:

- Treating provocations as actual proposals.
- Rejecting strange ideas before the movement step is complete.

## 9. Morphological Analysis

**Definition**: Decompose the problem into independent parameters, list possible values for each one, and explore non-obvious combinations.

**When to use**: Use it when the problem has three to five independent dimensions and the design space is large but structured.

**Procedure**:

1. Identify three to five independent parameters.
2. List three to five options for each parameter.
3. Build the matrix.
4. Explore combinations, especially the ones that do not look obvious.
5. Validate the most promising combinations for internal coherence.

**Example**: Evaluation output can vary by output target, detail level, comparison mode, and trigger, which exposes novel combinations such as editor-integrated on-save diffs or persistent trend ledgers.

**Pitfalls**:

- Choosing parameters that secretly depend on each other.
- Creating so many parameters that the matrix becomes unusable.

## 10. Brainwriting 6-3-5

**Definition**: A structured idea-building loop where each round extends previous ideas instead of starting from scratch.

**When to use**: Use it when multiple perspectives exist or when you want depth rather than a large pile of unrelated raw ideas.

**Procedure**:

1. Generate three seed ideas.
2. Build extensions or combinations on each seed.
3. Add another extension layer.
4. Focus on the strongest threads.
5. Synthesize two or three fully developed ideas.

**Example**: Worktree isolation improvements can evolve from environment files or health checks into a full pre-merge validation pipeline after several rounds of compounding.

**Pitfalls**:

- Evaluating too early.
- Replacing previous ideas instead of building on them.
- Prompting multiple models independently instead of passing the earlier ideas forward.

## 11. Random Entry

**Definition**: Introduce a random stimulus and force connections to the topic until one or two useful surprises emerge.

**When to use**: Use it as the fixation-breaker of last resort when every other technique keeps returning the same theme.

**Procedure**:

1. Pick a truly random word or object.
2. List five to eight attributes of it.
3. Force a connection from each attribute to the problem.
4. Keep all connections until the review step.
5. Develop only the promising directions.

**Example**: A random stimulus like `coral` can trigger ideas about incremental growth, symbiosis, staleness signaling, or onboarding shelter in documentation systems.

**Pitfalls**:

- Using a stimulus that is not actually random.
- Rejecting weak-looking connections too early.
- Expecting every random word to work equally well.

# DBT Distress Tolerance

> Purpose: Reference for `emotional-regulation` when the user needs short-term stabilization, practical distress tolerance, or emotion regulation skills.
> Relationship: This file provides the DBT-style techniques that the parent skill loads for acute distress, overwhelm, and interpersonal conflict.
> Boundary: DBT is explained here as practical skills for intense emotion, not as treatment or a substitute for professional help.

## Core Principle

Stabilize first, analyze later.
When distress is high, the user may need body-level regulation before thought work or values work.
Keep every exercise optional and safety-aware.
If crisis language appears, stop and route to human help.

## When To Use

Use this reference for acute distress, emotional overwhelm, panic-like activation, anger spikes, shame spirals, conflict aftermath, or "I need to get through the next few minutes."
Use it before CBT or ACT when the user sounds too activated to reflect.
Avoid it when the user wants only listening and validation.
Do not use it to minimize legitimate anger, grief, or boundary signals.

## TIPP Overview

TIPP is a fast body-regulation sequence.
Explain it in plain language as "change body state first."
Use only safe versions and encourage the user to skip anything medically unsafe.
If the user has health concerns, pregnancy, heart issues, fainting risk, eating disorder history, or pain, avoid intense temperature or exercise suggestions and choose paced breathing instead.

## TIPP Components

| Skill | Plain-Language Use | Safety Note |
|-------|--------------------|-------------|
| Temperature | Use cool water on the face or hold a cool pack briefly | Avoid extreme cold and stop if dizzy or uncomfortable |
| Intense exercise | Do brief movement like fast walking, stairs, or jumping jacks | Skip if medically unsafe or physically inaccessible |
| Paced breathing | Slow the exhale, such as inhale 4 and exhale 6 | Keep it gentle and stop if breath control increases distress |
| Progressive relaxation | Tense and release muscle groups | Skip painful areas and keep intensity low |

## 90-Second TIPP Lite

1. Ask the user to choose one safe body skill.
2. Suggest a brief action: cool water, brisk movement, longer exhale, or muscle release.
3. Keep the duration under 90 seconds unless the user asks to continue.
4. Ask what changed, even if the answer is "nothing."
5. Move to a lighter option or listening if it did not help.

## PLEASE Overview

PLEASE is a reminder that physical basics affect emotional bandwidth.
Explain it as "check the body supports."
Do not turn it into blame or lifestyle policing.
Use it after the immediate wave has passed.

## PLEASE Check

| Area | Coaching Prompt |
|------|-----------------|
| Physical illness or pain | Is your body dealing with illness, pain, medication changes, or exhaustion? |
| Eating and hydration | Have you eaten and had water recently enough for today? |
| Avoid mood-altering substances | Is anything making the emotional wave sharper or less predictable? |
| Sleep | Are you sleep-deprived enough that decisions should wait? |
| Exercise or movement | Would gentle movement help discharge activation? |

## Emotion Regulation: Opposite Action

Opposite action means choosing an action that moves against an unhelpful urge when the emotion does not fit the facts or is too intense for the situation.
Explain the plain-language test first: "Does this urge help you live your values right now?"
Use it carefully because anger, fear, and grief can carry valid information.
Do not use opposite action to suppress boundaries.

## Opposite Action Prompts

1. Name the emotion.
2. Name the urge.
3. Ask whether the urge fits the facts and helps the user's values.
4. If not, choose a small opposite or balancing action.
5. If yes, choose a wise and non-destructive version of the urge.

## Emotion Regulation: Check The Facts

Check the facts means distinguishing the event from interpretations and predictions.
Use it when the user is in conflict or believes something terrible is certain.
Keep it brief if distress remains high.
For deeper thought work, switch to the CBT reference.

## Conflict Use

In interpersonal conflict, stabilize before drafting messages.
Ask whether the user wants to calm down, understand the situation, or prepare a response.
If the user wants to send a message, suggest waiting until the intensity drops enough to choose tone.
Do not judge the other person or infer hidden motives as fact.

## Privacy Rule

Distress notes stay in `.pa/` by default.
Do not write conflict details, urges, or body-state notes into the vault unless the user explicitly approves export.
If exported, keep the summary practical and non-diagnostic.

## Common Pitfalls

| Pitfall | Correction |
|---------|------------|
| Analyzing while flooded | Use TIPP or paced breathing first |
| Giving unsafe body advice | Offer gentle options and mention skipping medically unsafe steps |
| Treating anger as bad | Ask what the anger is protecting before choosing a regulation tool |
| Pushing opposite action | Use it only when the urge is unhelpful or disproportionate |
| Keeping crisis in skill mode | Route crisis language to human help |

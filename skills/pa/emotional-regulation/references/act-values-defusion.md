# ACT Values And Defusion

> Purpose: Reference for `emotional-regulation` when the user feels stuck, avoidant, or pulled away from values-guided action.
> Relationship: This file provides the ACT-style values and defusion details that the parent skill loads when thought-checking is not the best fit.
> Boundary: ACT is explained here as making room for thoughts while choosing values-guided action, not as treatment.

## Core Principle

Help the user notice thoughts as thoughts, name what matters, and choose one workable next action.
Do not debate whether the thought is true unless the user explicitly wants a CBT-style thought record.
Do not turn values into obligations.
Values guide direction; they are not a stick for self-criticism.

## When To Use

Use this reference when the user feels stuck, avoidant, fused with a painful thought, disconnected from what matters, or caught in a values-action gap.
Use it when the user says "I know this thought is not helping, but I cannot shake it."
Use it when reasoning has become another loop.
Avoid it in acute crisis or when the user needs body-level stabilization first.
If crisis language appears, stop and route to human help.

## Values Clarification Overview

Values are chosen directions, not goals with finish lines.
A goal can be completed; a value keeps guiding choices.
Use plain domains and the user's language.
Do not assume the user's values from productivity, family roles, culture, or your own preferences.

## Life Domains

| Domain | Prompt |
|--------|--------|
| Health | What kind of care do you want to practice toward your body and energy? |
| Work | What kind of contribution or craft matters here? |
| Learning | What kind of growth feels alive or useful? |
| Relationships | What kind of presence do you want with people? |
| Family | What kind of role do you want to inhabit, if any? |
| Community | What kind of belonging or service matters? |
| Creativity | What kind of expression feels important? |
| Rest | What kind of recovery or spaciousness do you want to protect? |

## Importance And Alignment Check

Ask the user to pick one to three domains.
For each domain, ask what matters in plain words.
Then ask whether current action feels aligned, underfed, overextended, or unclear.
Avoid numeric scoring unless the user asks for a structured rating.
If using ratings, explain that they are rough navigation markers, not clinical measures.

## Values Prompt Sequence

1. "Which part of life does this feeling seem connected to?"
2. "What matters to you there, in your own words?"
3. "What action would move one millimeter toward that value?"
4. "What would be too much for today?"
5. "What support or boundary would make the next step more workable?"

## Cognitive Defusion Overview

Defusion means creating distance from a thought so the user can choose how to respond.
Do not tell the user the thought is false.
Help them notice, "I am having the thought that..."
The goal is freedom of action, not deleting the thought.

## Naming Thoughts

Use these prompts:

```text
I am having the thought that...
My mind is telling the story that...
This is the "I always mess this up" story again.
Thank you, mind, for trying to protect me.
```

Use a light tone only if it fits the user's style.
Do not mock the thought or the user.
If the thought contains danger or crisis content, route to human help instead of defusing.

## Leaves-On-A-Stream Metaphor

Explain it simply.
The user imagines placing each thought on a leaf floating down a stream.
They do not need to push the thought away or follow it.
They watch it appear, move, and maybe return.
Keep it optional because imagery does not work for everyone.

## 60-Second Defusion Exercise

1. Ask the user to name the thought in one sentence.
2. Ask them to say, "I am having the thought that [thought]."
3. Ask them to notice whether that creates even a little distance.
4. Ask what value they want to move toward despite the thought.
5. Ask for one small next action or one intentional pause.

## Values-Action Bridge

Choose one next action that is small, reversible, and value-linked.
Good actions are concrete and near-term.
Examples include sending one honest message, taking a five-minute walk, closing a tab, asking for help, or writing a private `.pa/` note.
Do not frame the action as proof of worth.

## Privacy Rule

Values and emotional notes stay in `.pa/` by default.
Do not write values clarification into the vault unless the user explicitly exports it.
If exported, write a minimal user-approved summary without labeling avoidance as pathology.

## Common Pitfalls

| Pitfall | Correction |
|---------|------------|
| Treating values as goals | Separate chosen direction from completed outcome |
| Moralizing values | Use values for orientation, not judgment |
| Arguing with the thought | Switch to CBT only if the user wants evidence checking |
| Making imagery mandatory | Offer leaves-on-a-stream as optional |
| Skipping safety | Route crisis language to human help |
